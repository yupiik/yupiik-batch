Getting Started

Yupiik Batch provides a UI to visualize a database populated using ExecutionTracer.

Dependency

<dependency>
  <groupId>io.yupiik.batch</groupId>
  <artifactId>yupiik-batch-ui-backend</artifactId>
  <version>${yupiik-batch.version}</version>
</dependency>

Add the JDBC driver for your database. You can create a Docker image using the main org.apache.openwebbeans.se.CDILauncher and this classpath.

TIP

Using jib makes Docker image creation straightforward.

Develop the frontend

The frontend uses Rsbuild, React 19, React Router 7 in declarative mode, and Ant Design 6. Maven installs Node 24.22.3 and npm 12.2.2, uses npm ci --include=dev --include=optional, runs lint and focused tests, and builds the resources packaged by the Java backend. Run these commands in yupiik-batch-ui/yupiik-batch-ui-frontend with the same Node/npm versions:

npm ci --include=dev --include=optional
npm run check
npm start

The development server binds to localhost on port 3000 and uses the checked-in JSON-RPC fixtures by default. To use a running local Java backend instead, start it with BATCH_BACKEND=http://localhost:8080 npm start. Only /jsonrpc is proxied, to an HTTP localhost origin; this is not a production proxy. The development middleware rejects foreign Host/Origin values and bounds request bodies and mock batch sizes. Do not expose the development server publicly.

npm run build writes to target/classes/META-INF/resources, with generated assets below /static/ and a CRA-shaped asset-manifest.json containing files and ordered entrypoints. Production browser targets retain the existing Browserslist policy; this does not promise support for browser versions no longer supported by React or Ant Design. The Java server serves SPA deep links separately from static resources, so missing assets return 404 rather than the application shell.

Run npm run audit:dependencies for the full dependency audit, including build tools. A successful build is not a clean security audit.

Extend the UI

Configure the server's frontend extension JavaScript URL to load a classic script registering window.yupiikBatchExtensions. The script is deferred and precedes every initial application bundle. Registration must be synchronous; promises and dynamic imports in that script are not awaited. The HTML template contains a unique <!--yupiik-batch-extensions--> marker, which must remain before all initial deferred scripts. Do not remove it when customizing the template.

WARNING

This upgrade changes the injected libraries to React 19, Router 7, and Ant Design 6. Extensions using ReactDOM.render, withRouter, Switch, Redirect, PageHeader, or removed Ant Design child-component APIs must migrate. There is no emulation of the old APIs.

Hooks receive the shared library registry as an object, not separate positional library arguments: 

window.yupiikBatchExtensions = {
    routes: function ({ React, router, antd, antdIcons }) {
        const e = React.createElement;
        function Foo() {
            return e(router.Link, { to: '/' }, 'Back home');
        }
        Foo.Breadcrumb = function () {
            return e(antd.Breadcrumb, { items: [
                { title: e(router.Link, { to: '/' }, e(antdIcons.HomeOutlined)) },
                { title: 'Foo' },
            ] });
        };
        return [{
            path: '/extensions/foo',
            component: Foo,
            sider: {
                selectedKey: 'foo',
                menu: {
                    attributes: { icon: e(antdIcons.FileOutlined) },
                    content: e(router.Link, { to: '/extensions/foo' }, 'Foo'),
                },
            },
        }];
    },
    commentWrapper: function (comment, { React }) {
        return React.createElement('span', null, comment);
    },
    routeDecorator: function (route, registry) {
        return route;
    },
    tableColumnsWrapper: function ({ columns, method }, registry) {
        return columns;
    },
    fetchJsonRpcHeaders: function () {
        return { 'X-Example': 'value' };
    },
};

Use explicit /* route suffixes for descendant matching; the old exact flag has no effect. Router 7 ranks specific routes ahead of wildcard routes, rather than using Router 5's first prefix match. Avoid duplicate paths and keep custom routes under /extensions/ so Java deep-link routing can serve them. The registry contains React, ReactDOMClient, router, fetchJsonRpc, antd, and antdIcons. fetchJsonRpc(method, params, dispatch) returns a cleanup function that aborts the request; return it from an effect to cancel stale requests.

An optional bootstrap override receives { ReactDOMClient, React, App, antd } and takes full ownership of creating and rendering the root:

window.yupiikBatchExtensions.bootstrap = function ({ ReactDOMClient, React, App }) {
    const root = ReactDOMClient.createRoot(document.getElementById('root'));
    root.render(React.createElement(React.StrictMode, null, React.createElement(App)));
};

Do not create another root on the same DOM node or invoke bootstrap twice. Plain extension scripts use React.createElement; JSX requires a separate build step.
